# Softmax, gradient descent, optimizers, and quantization are the foundation of modern training

This file summarizes the major topics that every AI trainee should understand deeply.

## Must-learn concepts
- softmax
- cross-entropy
- gradient descent
- SGD
- Adam
- AdamW
- learning rate schedule
- regularization
- bottleneck and scaling awareness
- model initialization
- mixed precision
- quantization
- inference optimization
- distributed training
- PEFT and LoRA

## Why these are essential
They influence:
- training stability
- convergence speed
- memory usage
- throughput
- deployment cost
- model quality

## Learning path
Start with small model training in NumPy. Then move to PyTorch. Then learn how the same concepts apply in distributed and frontier-scale training.

This is how you go from understanding a single model to understanding large-scale AI systems.
