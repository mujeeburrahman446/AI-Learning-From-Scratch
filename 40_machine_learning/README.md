# Machine Learning

This phase introduces classical machine learning.

## Core ideas
- supervised learning
- unsupervised learning
- feature engineering
- train/test split
- overfitting and underfitting
- bias/variance
- evaluation metrics
- cross-validation

## Algorithms to learn

### Supervised learning
- linear regression
- logistic regression
- decision trees
- random forest
- gradient boosting
- XGBoost
- SVMs
- k-NN
- naive Bayes

### Unsupervised learning
- K-means
- hierarchical clustering
- DBSCAN
- PCA

### Model evaluation
- MAE, MSE, RMSE
- accuracy, precision, recall, F1
- ROC-AUC
- confusion matrix
- cross-validation

## ML workflow
1. define the problem
2. collect and clean data
3. split data
4. train a baseline model
5. evaluate the baseline
6. tune hyperparameters
7. validate generalization
8. deploy or iterate

## Important concepts
- feature scaling
- one-hot encoding
- missing value handling
- target leakage
- class imbalance
- regularization

## Practical projects
- house price prediction
- customer churn prediction
- spam detection
- fraud detection
- recommendation baseline

## Implementation style
This repository emphasizes:
- simple implementations from scratch
- intuition before using frameworks
- then library-based learning with scikit-learn

## Example from scratch
- linear regression using NumPy
- logistic regression using gradient descent
- decision tree logic for simple classification

## Goal
By the end of this section, the learner should understand how machine learning models learn and how to evaluate them correctly.
