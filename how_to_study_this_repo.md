# How to Study This Repo

This repository is a step-by-step curriculum, not a random collection of topics.

## Recommended learning flow

### Step 1: Start with foundations
Read and practice:
- Python fundamentals
- Linux and Git basics
- statistics and probability
- linear algebra
- coding structure and clean software practices

### Step 2: Learn data and analytics
Study:
- NumPy
- Pandas
- SQL
- EDA
- visualization
- data cleaning

### Step 3: Learn classical ML
Study:
- regression
- classification
- clustering
- feature engineering
- evaluation metrics
- model selection

### Step 4: Learn deep learning
Study:
- neural networks
- backpropagation
- PyTorch
- loss functions
- optimizers
- transformers and attention

### Step 5: Learn AI systems and tooling
Study:
- CUDA and GPU basics
- Docker and Kubernetes
- MLOps and deployment
- LLM tools and frameworks

### Step 6: Learn RL and post-training
Study:
- MDPs, Q-learning, RLHF, PPO, DPO, and alignment

### Step 7: Learn agents and frontier AI
Study:
- tool use
- memory
- planning
- multi-agent systems
- distributed training
- inference optimization

### Step 8: Practice with capstone projects
Build at least one full project in each major phase.

## Rules for learning
- do not skip theory
- do not skip code practice
- do not jump to large models before understanding small ones
- keep notes and examples
- build small projects before large ones
- revisit older sections when needed

## Best habit
Each week:
- read one theory section
- code one exercise
- write a short summary
- test one small project

This is how the repo is meant to be used.
