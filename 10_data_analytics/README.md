# Data Analytics

This section teaches the core workflow for understanding data before building models.

## Core tools
- Python
- NumPy
- Pandas
- SQL
- Matplotlib
- Seaborn
- Jupyter Notebook
- Plotly (optional)

## Learning flow

### 1. NumPy from scratch
Learn:
- arrays
- indexing and slicing
- broadcasting
- reshaping
- vectorized operations
- matrix operations
- random generation

### 2. Pandas fundamentals
Learn:
- Series and DataFrame
- reading CSV/JSON/Excel
- filtering, selecting, sorting
- grouping and aggregation
- joins and merges
- missing values
- date handling

### 3. SQL fundamentals
Learn:
- SELECT, WHERE, ORDER BY
- GROUP BY
- JOINs
- subqueries
- CASE statements
- window functions

### 4. Exploratory Data Analysis (EDA)
Learn:
- describe dataset
- missing values patterns
- outliers
- distribution analysis
- correlation
- feature relationships
- dashboard-style summaries

### 5. Visualization
Learn:
- line plots
- scatter plots
- histograms
- box plots
- heatmaps
- bar charts
- pair plots

## Typical analytics projects
- sales data analysis
- customer segmentation analysis
- churn analysis
- ad campaign performance
- market trend analysis

## Skills developed
- reading messy data
- cleaning data correctly
- summarizing data
- identifying anomalies
- preparing data for modeling

## Mini assignments
- load a CSV and summarize columns
- identify missing values and impute them
- plot feature distributions
- compute correlations
- answer business questions using SQL and Pandas

## Goal
By the end of this section, the learner should be able to analyze data, generate insights, and prepare clean datasets for ML.
