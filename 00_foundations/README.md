# Foundations

This section is the base of the full AI learning path. If the learner is weak here, the rest of the roadmap becomes harder than necessary.

## Goals
- learn Python from scratch
- become comfortable with the terminal
- understand Git and GitHub workflows
- build problem-solving habits
- understand statistics, probability, and linear algebra

## Beginner sequence

### 1. Python from scratch
Learn:
- variables, numbers, strings
- lists, tuples, dictionaries, sets
- loops and conditionals
- functions and scope
- modules and imports
- file IO
- exceptions
- classes and OOP basics
- comprehensions
- virtual environments

### 2. Linux and shell
Learn:
- pwd, ls, cd, mkdir, rm, cp, mv
- cat, grep, sed, awk
- chmod, chown
- environment variables
- pipes and redirection
- SSH basics

### 3. Git and GitHub
Learn:
- git init
- git status
- git add
- git commit
- git push
- git pull
- git branch
- merge and rebase basics
- pull requests

### 4. Basic programming practice
Build mini-projects:
- calculator
- todo app
- password generator
- number guessing game
- file organizer
- CSV reader

### 5. Statistics and probability
Learn:
- mean, median, mode
- variance, standard deviation
- distributions
- sampling
- correlation
- conditional probability
- Bayes rule

### 6. Linear algebra basics
Learn:
- vectors and matrices
- dot product
- matrix multiplication
- transpose
- inverse
- eigenvalues and eigenvectors
- gradients and derivatives basics

## Why this matters
Every advanced AI topic depends on these fundamentals:
- model training uses gradients
- data science uses statistics
- deep learning uses matrices and vector operations
- distributed systems use Linux and Git workflows

## Mini practice problems
- write a function to calculate mean and standard deviation
- implement matrix multiplication manually
- write a script to load a CSV file
- create a small CLI app
- build a simple class-based project

## Milestone
By the end of this module, the learner should be able to:
- read and write Python scripts
- use Git professionally
- work in the terminal
- reason about data and math
- begin ML and DL concepts without confusion
