# Foundations README

This section begins the journey.

Topics:
- Python basics
- Linux fundamentals
- Git and GitHub
- OOP and modularity
- Data structures
- Statistics and probability
- Linear algebra basics

Important idea:
AI starts with strong fundamentals. We do not skip the basics.

## Suggested learning order
1. Python syntax and variables
2. loops, conditionals, functions
3. lists, dictionaries, tuples, sets
4. file handling and modules
5. OOP basics
6. Git and GitHub fundamentals
7. Linux shell basics
8. statistics and probability
9. linear algebra basics

## Goal
By the end of this section, the learner should feel comfortable writing Python, navigating the terminal, using GitHub, and understanding the math behind AI.
