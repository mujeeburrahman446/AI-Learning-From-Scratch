# Statistics and Probability Theory for AI

Statistics and probability are core to understanding datasets, hypothesis testing, model behavior, and inference.

## 1. Descriptive statistics
- mean
- median
- mode
- variance
- standard deviation
- percentiles

## 2. Probability basics
- events
- independent events
- conditional probability
- Bayes theorem

### Bayes rule
```text
P(A|B) = P(B|A) * P(A) / P(B)
```

Bayes theorem is foundational in probabilistic reasoning and many ML algorithms.

## 3. Random variables
A random variable is a numerical outcome of a random process.

Types:
- discrete random variables
- continuous random variables

## 4. Distributions
Important distributions in AI:
- Bernoulli
- binomial
- Gaussian / normal
- Poisson
- uniform

## 5. Statistical inference
- confidence intervals
- hypothesis testing
- p-values
- sampling
- standard error

## 6. Correlation and covariance
These tools measure relationships between variables.

## 7. Why this matters in AI
- model evaluation uses distributions and variance
- feature engineering uses statistical summaries
- Bayesian methods rely on probability
- generative models use probability distributions
- optimization and learning depend on statistical assumptions

## 8. Example
Suppose a model predicts spam. We care about:
- precision
- recall
- false positive rate
- class imbalance

These are statistical quantities used for evaluation.

## Summary
Statistics and probability give AI models a language for dealing with noise, uncertainty, and variation in real-world data.
