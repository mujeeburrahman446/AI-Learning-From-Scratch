# Generative AI and LLM Foundations

This module covers the fundamentals behind modern generative AI.

## 1. Tokenization
Text is converted into tokens before model processing.

## 2. Embeddings
Tokens are embedded into vectors that capture meaning.

## 3. Transformer architecture
The transformer uses:
- token embeddings
- positional embeddings
- self-attention
- multi-head attention
- feed-forward networks
- residual connections

## 4. Prompt engineering
- zero-shot prompting
- few-shot prompting
- chain-of-thought prompting
- structured prompting

## 5. RAG (Retrieval-Augmented Generation)
RAG combines:
- retrieval system
- document store
- embedding search
- LLM generation

## 6. Fine-tuning
Fine-tuning adapts a pretrained model to a task or domain.

## 7. Evaluation methods
- exact match
- BLEU/ROUGE (for text tasks)
- human evaluation
- rubric-based judge models
- safety evaluations

## 8. Guardrails
- prompt injection defenses
- output filtering
- retrieval restrictions
- policy checks

## 9. Goal
Learn how modern generative systems convert text, context, and data into useful outputs.
