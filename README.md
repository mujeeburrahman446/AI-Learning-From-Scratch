# AI Learning From Scratch to Frontier

This repository is a complete learning roadmap and project starter for mastering AI from fundamentals to frontier-level systems.

It covers:
- Python from scratch
- Data Analytics
- Data Science
- Data Engineering
- Machine Learning
- Deep Learning
- CUDA / GPU Programming
- DevOps and Infrastructure
- MLOps and GenAI Ops
- Generative AI and LLMs
- Reinforcement Learning and Post-Training
- Agents and Agentic AI
- Frontier AI and scaling
- APIs, deployment, and production patterns

The goal is simple:
- start with fundamentals and toy implementations
- understand the math and architecture
- connect concepts to real-world tools
- build practical projects
- then move toward production-grade and frontier AI systems

## Learning Principle

This repository is designed to teach:
1. the theory
2. the math
3. small implementations from scratch
4. the real-world libraries and tools
5. the production patterns and frontier concepts

That is the path from beginner to AI engineering.

## Suggested study order

If you are a beginner, follow this route:

1. Python
2. Linux + Git
3. Data structures and algorithms
4. Statistics and probability
5. Linear algebra
6. NumPy and Pandas
7. SQL and EDA
8. Machine learning basics
9. Deep learning
10. CUDA and GPU basics
11. DevOps and deployments
12. LLMs and GenAI
13. RL and post-training
14. Agents and Agentic AI
15. Frontier AI systems

## Practical Rule

Never jump directly to trillion-parameter training.
Instead:
- train tiny models from scratch
- understand the mechanics
- scale the ideas conceptually
- then learn distributed training, inference, serving, and production scale
