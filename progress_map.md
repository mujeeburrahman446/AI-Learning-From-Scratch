# Beginner / Intermediate / Advanced Progress Map

## Beginner
This level covers:
- Python basics
- Linux and Git
- statistics and probability
- linear algebra basics
- NumPy and Pandas
- SQL and EDA
- classic ML basics

### Beginner goal
Build confidence writing code and working with data.

## Intermediate
This level covers:
- deep learning concepts
- PyTorch fundamentals
- CNNs and RNNs
- transformers and attention
- model evaluation
- CUDA basics
- Docker and deployment basics
- LLM fundamentals

### Intermediate goal
Build and train small models, understand optimization, and work with real AI tools.

## Advanced
This level covers:
- RL and post-training
- DPO, PPO, RLHF, alignment
- agents and tool use
- distributed training
- edge and cloud deployment
- quantization and inference optimization
- frontier AI systems and scaling

### Advanced goal
Understand how real AI systems are trained, optimized, served, and scaled at production-level complexity.

## Learning progression
The learner should move from:
- code and logic
- to data and models
- to deep learning and LLMs
- to RL and post-training
- to agents and production AI
- to frontier-level AI systems
