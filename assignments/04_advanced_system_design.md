# Advanced Assignment: Frontier System Design

## Task
Design a production-ready AI system that includes:
- data ingestion pipeline
- model or LLM workflow
- inference or generation layer
- monitoring and evaluation
- safety guardrails
- deployment architecture

## Requirements
Your design should include:
- diagram or simple architecture description
- rationale for each component
- tradeoffs between cost, speed, and quality
- security and reliability considerations

## Example system
- ingestion of documents
- embedding pipeline
- vector database
- retrieval system
- LLM generation layer
- evaluation and monitoring
- deployment via container or k8s

## Learning goal
This assignment helps turn theory into systems thinking. It is one of the final steps before real-world AI engineering work.
