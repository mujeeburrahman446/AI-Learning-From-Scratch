# MLOps and GenAI Ops

MLOps is the engineering system that turns a model into a production asset.

## 1. Core MLOps principles
- reproducibility
- versioning
- experiment tracking
- deployment automation
- monitoring
- rollback safety

## 2. Tools
- MLflow
- DVC
- Weights & Biases
- Kubeflow
- Airflow
- Docker
- Kubernetes

## 3. ML lifecycle
1. data preparation
2. feature engineering
3. model training
4. validation
5. packaging
6. model registration
7. deployment
8. monitoring
9. retraining

## 4. GenAI Ops specific concerns
- prompt management
- evaluation pipelines
- guardrails
- retrieval quality
- context window management
- tool use safety
- token cost and latency control

## 5. Key metrics
- accuracy
- precision/recall
- latency
- throughput
- p95 latency
- hallucination rate
- safety violations
- retrieval recall

## 6. Goal
MLOps ensures AI systems are not only built, but also managed, evaluated, updated, and scaled responsibly.
