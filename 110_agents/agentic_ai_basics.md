# Agentic AI Basics

Agentic AI is about building systems that act with goals, tools, memory, and feedback loops.

## 1. Agent components
- model
- tools
- memory
- planner
- executor
- evaluator

## 2. ReAct pattern
Reason + Act loop:
1. observe state
2. think
3. choose tool or action
4. act
5. loop until done

## 3. Tool use
Examples:
- web search
- calculator
- Python interpreter
- database query tool
- file system access
- API calls

## 4. Memory
- short-term memory
- long-term memory
- retrieval from documents
- conversation state
- user preferences

## 5. Multi-agent systems
- specialized agents
- coordinator agent
- shared context
- task decomposition

## 6. Use cases
- coding assistants
- research agents
- ops agents
- workflow automation agents
- customer support agents

## 7. Goal
Understand how agentic systems move beyond chat responses toward autonomous execution.
