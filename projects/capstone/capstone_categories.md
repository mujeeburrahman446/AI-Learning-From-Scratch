# Capstone Project Categories

Final projects should combine theory, implementation, and deployment.

## Category 1: Data and analytics projects
- sales analysis dashboard
- churn prediction pipeline
- customer segmentation study
- KPI and monitoring dashboard

## Category 2: Classical ML projects
- house price prediction
- spam detection
- credit risk modeling
- recommendation system

## Category 3: Deep learning projects
- CNN image classifier
- sentiment analysis
- time-series forecasting
- small transformer implementation

## Category 4: LLM and GenAI projects
- RAG assistant
- Q&A over documents
- local LLM chat app
- retrieval and summarization system

## Category 5: Agentic AI projects
- code-generating agent
- research and summarization agent
- multi-agent workflow assistant
- tool-calling reasoning app

## Category 6: Production AI projects
- Dockerized AI API
- Kubernetes deployment
- monitoring and observability stack
- model serving project

## Category 7: Frontier AI projects
- distributed training demo
- quantized inference benchmark
- vector database and retrieval pipeline
- large-model scaling and serving study

## Final capstone requirement
Every final project should include:
- problem statement
- data or knowledge source
- architecture explanation
- code and model design
- evaluation metrics
- deployment or demonstration strategy
- summary of tradeoffs and limitations
