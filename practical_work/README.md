# Practical Work

This folder is for hands-on learning. The idea is simple:
- read the theory
- do the exercise
- validate by running code
- reflect on the result

## Practical work plan

1. Python basics lab
2. NumPy and EDA lab
3. Linear regression implementation
4. Small PyTorch model
5. Retrieval-based simple RAG demo
6. Tool-calling agent simulation

## How to use this section

Run each file individually and understand:
- what the code is doing
- what assumptions it makes
- how the logic connects to the theory
- what would change in a larger model

## Suggested sequence

- start with `01_python_lab.py`
- then `02_numpy_eda.py`
- then `03_linear_regression_from_scratch.py`
- then `04_pytorch_quick_model.py`
- then `05_rag_demo.py`
- then `06_agent_tool_demo.py`

## Goal

The learner should move from reading to implementing. Practical work is how theory becomes real skill.
